# S0 基准报告（M1 遗留项清偿）

> 版本：v1.0 · 日期：2026-08-01
> 上游：[M2 计划](./M2-平台一期详细设计与开发实现计划.md) §5.2 Sprint 0 · 体例沿用 [M1 基准报告](./M1-基准测试报告.md)

## 诚实边界声明

本轮在**单机双 JVM 进程 + 真实 netty 网络栈（localhost）**完成——验证了传输层替换的正确性与开销，
但**不等价于真机 LAN/WAN**：未经过物理网卡与交换机，RTT≈0。macOS 无 tc/netem，
真机 LAN/WAN-sim 矩阵按 M2 附录 A 口径在双机环境补测后，本报告升 v2。
环境同 M1（Apple M4 / 32GB / JDK 17.0.15 / mpc4j ea3b9aa 纯 Java 路径）。

## 遗留项 1：netty 双进程 PSI ✅

`NettyPsiRunner`（mpc4j RobustNettyRpc，`LocalPsiRunner` 同语义换传输）：

| 场景 | 结果 | 对照（内存 RPC） |
|---|---|---|
| S 档 RR22（双进程，CI 门禁用例） | 校验通过，含 JVM 启动全程 8.3 s | — |
| M 档 RR22（双进程） | **9.1 s**，client 发送 36.0 MB / server 15.2 MB，校验通过 | 9.5 s（差异在噪声内） |

结论：**netty 传输栈开销可忽略**；`NettyPsiPartyMain` 即双机部署入口（改 yaml 端点即可）。
安全注记：RobustNettyRpc 通道为明文，协议面跨不可信网络需叠加 TLS/网络层加密（S2 处理）。

## 遗留项 3：RR22 分批求交 ✅

`BatchedRr22Psi`：client 集合切批、逐批与 server 全集求交、并集。
S 档强制 3000/批（4 批）与单次求交结果完全一致。
泄露语义（每批交集规模）已写入类文档，契约字段 `batchLeakageAccepted` 在 S2 落地。

## 遗留项 4：盲化因子预计算池 ✅（远超目标）

`ObfuscationFactorPool`（后台预生成 r^n mod n²）+ `PooledPaillierEncryptor`
（g=n+1 快速加密 + 池因子模乘，全程无在线模幂）：

| 指标 | 实测 | 对照 |
|---|---|---|
| 在线加密（含盲化）吞吐 | **64,516 条/秒**（满池，降级 0 次） | 同步盲化 945 条/秒 → **68×** |
| 正确性 | 与 javallier 解密互通（含负数），与原生密文可混合加法 | — |

**SLA「预计算池在线加密 ≥1 万条/秒」达成并上修为 ≥3 万条/秒**（留池水位余量）。
百万条出域加密在线耗时从 18 分钟压缩到 **~30 秒 + 离线池预生成**。
